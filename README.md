# Trainings Dashboard

Instructor-led courses and hands-on workshops delivered by the UiPath Technical Partner Success team, for UiPath partners and customers: what each covers, who it's for, the prerequisites and how to register.

The site is a single self-contained `trainings-dashboard.html` published with GitHub Pages:

https://uipath-technical-partner-success.github.io/Trainings-Dashboard/trainings-dashboard.html

To update the content, edit the `D` data block at the top of the script in `trainings-dashboard.html` and commit.
